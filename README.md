# 🌐 Sistema SCADA Web

Este é um protótipo de sistema **SCADA (Supervisório de Automação Industrial)** desenvolvido em ambiente web para monitoramento e controle de processos de manufatura em tempo real.

## 🚀 Funcionalidades
* **Navegação Dinâmica (SPA):** Alternância instantânea entre as telas dos setores industriais através do menu lateral, sem recarregamento de página.
* **Layout Responsivo:** Estrutura construída com Flexbox moderna para melhor organização dos componentes.
* **Organização Setorial:** Telas preparadas para receber as variáveis e tags de monitoramento de quatro áreas essenciais:
  * Forjaria
  * Usinagem
  * Montagem
  * Pintura

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação das divisões estruturais e blocos de conteúdo.
* **CSS3:** Estilização visual, bordas arredondadas, contornos e alinhamentos simétricos com Flexbox.
* **JavaScript (ES6):** Lógica de manipulação do DOM (tirar e botar classes) para troca de telas em tempo de execução.

## 📂 Estrutura do Projeto
* `index.html` — Arquivo principal com a casca do supervisório e os containers das telas.
* `Style.css` — Arquivos de estilos visuais, contornos e posicionamento.
* `Script.js` — Motor em JavaScript que gerencia o fluxo de exibição e ocultação das telas.
